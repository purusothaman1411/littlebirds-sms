23. CURRENT PROJECT OBSERVATIONS
================================

- School.java is NOT part of the current project structure.
- LoginManager -> StaffFileHandler -> staff.txt is the authentication flow.
- Role contains:
    HEADMASTER
    SUBJECT_STAFF
    WORKING_STAFF
    MANAGEMENT_STAFF

- StaffPermissions is used for role-based access control.
- Custom exceptions currently include:
    StudentNotFoundException
    StudentAlreadyExistsException
    TeacherNotFoundException
    TeacherAlreadyExistsException
    InvalidMarkException

- Model classes include:
    Student
    Teacher
    Marks
    Attendance

- Business operation classes include:
    StudentOperations
    TeacherOperations
    MarksOperations
    AttendanceOperations
    ReportOperations

- Attendance currently records attendance using student ID and Present/Absent input.
- Marks operations contain standard/group based subject selection logic.
- Report operations combine student, marks and attendance information.
- Current Student ID type is int.
- bin contains compiled .class files and is not a business-logic layer.
- plan contains project planning and documentation files and should be retained.
